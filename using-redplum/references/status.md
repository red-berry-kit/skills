# 实现范围

正式源码包含公共运行时（`app`、`config`、`migrate`）、整体需求、设计文档与开发 Skill。
Red Plum CLI 与项目模板、独立模块模板在独立仓库 `red-plum-kit/cli`，本仓库不再包含
CLI 代码与构建产物，验收脚本从外部 CLI 源码目录编译 CLI。完整工程验收按
交付规格（仓库上下文，不随 Skill 发布） 执行；最终结论以独立验收报告为准。

## 实现能力

- 项目及本地模块创建，支持外部模板仓库与 Git ref。
- 模块依赖解析、版本锁定、替代选择、源码恢复及失败回滚。
- Go / pnpm 工作区与后端装配、前端入口和路由生成。
- 配置加载、严格校验、Schema 导出及 Fx 注入。
- SQLite 项目级迁移事务、版本账本、校验和与锁等待。
- Huma API、OpenAPI / Orval 客户端与完整业务示例。
- 类型、格式、模块和 UI 边界检查，分层测试及报告门禁。
- 开发进程管理、单二进制和分离构建。
- 项目 `AGENTS.md` 模板与七项可独立发布的 Skill。

源码工程通过根 `Taskfile.yml` 提供 `check`、`test`、`build` 和 `acceptance` 入口。`build` 只打包
Skill 发布包，CLI 由 `red-plum-kit/cli` 构建。完整验收脚本见 执行说明（仓库上下文，不随 Skill 发布），
运行前需用 `--cli-dir` 或 `REDPLUM_CLI_DIR` 指定 CLI 源码目录；规格、实施任务与证据位于
交付目录（仓库上下文，不随 Skill 发布）。

## 交付边界

Skill 与配套规范由用户自行安装和更新，CLI 不管理；发布包包含从 `docs/` 生成的 `references/`。实际实施中的 Skill 使用证据见 验证记录（仓库上下文，不随 Skill 发布），不将手动读取等同于客户端自动加载。

CI 工作流已提供；远程执行与正式版本发布需在实际托管仓库中完成。业务项目 CI 使用仓库变量指定 Red Plum 运行时源码仓库。公开文档站的 `llms.txt` 随文档站建设实现；具体基础业务模块按需求单独设计。

技术选型的独立实验见 验证记录（仓库上下文，不随 Skill 发布），实验结果不替代正式工程验收。
