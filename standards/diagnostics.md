# 错误反馈与诊断

本页规定错误分类、错误聚合、用户反馈及故障／性能日志；翻译与语言状态见[国际化](i18n.md)，校验执行时机见[配置校验分层](design.md#配置校验分层)。

## 失败分类

- 分类依据：先判断失败是否属于程序预期；协议状态或错误传播方式不能单独作为依据。
- 正常拒绝：因输入、身份权限或业务状态不满足约定而被预期拒绝时，正常返回业务错误，向用户展示可公开原因与调整方式；不将该拒绝记录为诊断事件，包括 INFO 或 DEBUG。
- 程序故障：实现或依赖出现非预期失败、不变量被破坏时，向用户提供安全说明与恢复方式，必要时提供关联编号；日志保留技术原因、上下文、关联标识及发生阶段。
- 预期取消：按约定取消操作时，展示取消后的状态并保留允许继续的内容，不记程序错误；按性能记录需要保留状态和耗时。
- 正常执行：按产品流程呈现进度与结果，记录执行和等待耗时。
- 边界判断：相同对外状态按实际原因区分正常业务结果与程序或依赖故障。
- 访问记录：已有访问及性能日志可保留正常拒绝的请求状态和耗时，不打印拒绝详情，不将其计为程序故障。

## 错误反馈与聚合

- 一次报全：同一次校验里的多条问题用 `errors.Join` 合并返回，不修一个报一个。
- 字段定位：错误写成 `分组.字段: 原因`，配置错误使用模块分组；分组前缀只出现一次。
- 文本边界：错误文本不混入日志行；响应遵守接口错误契约。

## 用户反馈

- 失败覆盖：所有用户操作在校验、调用与异步执行中的失败均提供可见反馈，包括业务拒绝、通信失败及超时；不只写日志，不显示为成功或无限等待。
- 反馈内容：说明失败操作、可公开原因及可执行的纠正、恢复或求助方式；保留可纠正原因的具体语义，需要维护者排查时携带关联编号。
- 安全说明：日志和内部异常不直接充当用户提示；内部异常展示安全说明与恢复指引，技术细节留在诊断日志。
- 展示位置：字段错误显示在对应字段，其余错误在所属操作范围内显示；服务端未知字段位置也提供操作级反馈。
- 显示时机：收到错误后立即显示，持续到相关输入纠正、新结果替代或流程结束。
- 后台复查：不得卸载表单、清空输入或抹掉未解决错误；后台刷新失败可保留旧数据并标明刷新未成功。
- 表单接入：生命周期按 ui 模块的 `README.LLMS.md`（“表单与日期控件接入”）执行。
- 异步终态：任务受理后仍须跟踪执行结果，失败提供可读取的终态与恢复入口。

## 程序故障日志

- 定位内容：程序故障及非预期依赖故障记录错误类别、原因链、发生阶段和必要上下文；未预期异常在捕获边界保留定位所需堆栈。
- 日志字段：包含时间、级别、模块、操作、请求／任务关联标识；按场景补充资源标识、调用目标、尝试次数及超时配置。
- 记录边界：在掌握完整上下文的边界记录一次故障，下层传播原因链，不逐层重复打印。
- 重试记录：异常重试逐次保留技术失败和耗时，最终记录恢复或失败结果；重试成功不删除异常记录。
- 日志级别：WARN／ERROR 按实际影响和项目约定选择，不将正常业务拒绝升级为警告。
- 关联标识：贯穿请求与异步任务；用户需要联系维护者时，通过已有响应头或公开错误契约提供编号。客户端网络失败时，不虚构后端已接收的请求或日志。
- 数据脱敏：响应与日志均过滤密码、令牌、Cookie、密钥及不必要的个人数据；SQL 参数、请求体和第三方响应按字段脱敏。

## 性能耗时日志

- 链路覆盖：沿实际执行链记录操作总耗时及各处理阶段，覆盖调度与同步等待、资源读写与事务、外部依赖调用，以及初始化、后台运行和关闭的生命周期阶段。
- 阶段记录：记录阶段结果及带明确单位的耗时；失败和超时也记录耗时，长阶段记录开始与完成。
- 耗时关系：耗时包含等待；嵌套与并发阶段保留父子关系，不重复相加。
- 记录粒度：复用项目日志级别区分汇总与细节，调试时能取得完整阶段信息，不只记录总耗时；不为每行代码或简单函数调用机械打印日志。
- 依赖接入：优先复用已有日志与追踪能力及依赖提供的观测入口，按[依赖现有能力优先](conventions.md#依赖现有能力优先)接入；仅为缺失的业务阶段补最小埋点，不复制计时包装或另建同类框架。
- 证据类型：指标和 trace 不替代明确要求的耗时日志。

## 验收

- 正常操作错误：用户能看到原因并完成纠正；后台复查后错误与可继续使用的输入仍在；后端没有该拒绝的业务错误日志。
- 程序或依赖故障：用户得到安全的恢复反馈；开发者能通过关联标识查到技术原因及发生阶段，日志无重复和敏感值。
- 性能诊断：从实际日志能分辨总耗时、阶段及外部调用耗时，定位等待或瓶颈；超时和失败路径也有耗时。
- 验证范围：按变化选择实际场景，针对受影响链路分别记录界面与日志证据；编码和审查使用同一判据，不只检查是否返回错误或打印日志。
- 文档核对：纯文档变更核对规范与引用，不将静态检查表述为应用链路通过。
