# 国际化（i18n）

本页规定翻译归属、语言状态与资源、时间语义及对应验收；错误如何反馈见[错误反馈与诊断](diagnostics.md)，技术选型见[技术选型](stack.md)。

## 语言契约与资源

- 适用范围：新增或调整用户可见消息或语言格式时，核对并复用项目的支持语言、默认语言、语言选择与持久化、缺失翻译回退及前后端翻译分工。
- 决策缺口：未确定的语言范围与技术选型保留为缺项，不擅自固定支持语言或新增翻译框架。
- 状态归属：应用统一管理语言策略。
- 资源装配：模块随包提供自己命名空间内的消息资源，通过公开装配契约接入；CLI 创建应用和添加模块后按约定自动装配，消费应用只填写必要配置。
- 资源隔离：模块不读取宿主私有翻译文件，同名消息不跨模块覆盖。
- 消息表达：翻译键表达稳定语义；动态值通过完整消息的参数传入，沿用已选库的插值和复数能力。
- 翻译归属：明确前后端分工，可按消息类别划分；同一消息只由约定的一层翻译，覆盖对外返回文字的后端接口，不只翻译页面。前端细则读取 ui 模块的 `README.LLMS.md`（“国际化”）。
- 数据保真：用户输入与业务数据保留原值；协议字段、资源标识与路由保持稳定。
- 错误身份：语言不改变机器可识别的错误身份，也不改变日志和内部异常的错误分类；如何向用户反馈按[用户反馈](diagnostics.md#用户反馈)执行。

## 时间语义

- 纯日期：不做时区转换，保留日期语义。
- 时间点：前端显示和编辑默认按用户本地时区转换，保留未修改的原始值及接口原始时间语义；接入细则读取 ui 模块的 `README.LLMS.md`。
- 时区来源：语言选择不决定时区；接口收到的有效偏移不能直接作为显示时区。

## 验收

- 文案与格式：按约定语言范围实测新增及受影响的文案、可访问名称、格式、缺失翻译回退与长文案布局。
- 语言切换：支持切换时，界面文案与已显示反馈随之更新，会话与表单保留；单语言范围核对界面及响应语言一致。
- 后端消息：覆盖业务错误、自动请求校验、未识别内部错误及本次受影响的其他用户可见消息。
- 语义一致：不同语言下，HTTP 状态、错误身份、字段位置和业务结果保持一致。
- 语言协商：服务端支持协商时，验证默认、支持、不支持或无效语言，以及并发不同语言请求相互隔离。
- 前端翻译：采用前端翻译模式时，验证结构化错误及未知错误的安全回退。
- 模块接入：可复用模块须在干净应用通过真实 CLI 添加后，验证资源装配及前后端消息链路；翻译函数、资源文件或视觉检查不能替代实际国际化验收。
- 时间验证：按受影响的纯日期、时间点显示与编辑核对上述语义；跨语言与跨时区验收分别记录，不互相替代。
- 结果记录：记录实际语言、入口与结果，未实现或未执行项保留缺项。
